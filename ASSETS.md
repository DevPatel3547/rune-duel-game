## Pipeline

```bash
node tools/fetch_assets.mjs   # download originals -> assets/src/ (gitignored)
node tools/pack_assets.mjs    # resize + WebP      -> xr/public/tex/
```

Sources are ~57MB; the packed set that ships is ~3MB (95% smaller). Normal maps
are encoded at higher quality than the rest, because compression artefacts in a
normal map become visible *lighting* errors rather than merely softer pixels.

The scanned set is **runtime-cached** by the service worker rather than
precached: it would triple the install payload and delay first interaction, and
the game is fully playable while it streams in. After one visit it is available
offline at full fidelity.

## Character

`xr/public/wizard.glb` is generated by `tools/build_human.py`, run headlessly in
Blender, from the **MakeHuman base mesh** via
[MPFB2](https://github.com/makehumancommunity/mpfb2).

The MakeHuman base mesh and its system assets are released **CC0**, explicitly so
that characters made from them carry no licensing obligations. MPFB2 itself is
AGPL, but it is a *build-time tool* — it is not distributed with the game and no
part of it ends up in the bundle, so its licence does not reach the shipped
artefact.

### Setup (one-time, for regenerating the character)

```bash
curl -L -o mpfb2.zip https://github.com/makehumancommunity/mpfb2/archive/refs/tags/v2.0.17.zip
unzip mpfb2.zip
cp -R mpfb2-*/src/mpfb "$HOME/Library/Application Support/Blender/5.2/extensions/user_default/mpfb"
blender --background --python tools/build_human.py
```

Blender 4.2+ uses the **extensions** directory, not the legacy `scripts/addons`
path — installing to the latter silently fails to register, and the module is
then addressed as `bl_ext.user_default.mpfb`.

The costume (robe, sleeves, hood, pauldrons, belt) is generated on top and bound
to the same skeleton. It **measures the actual body** rather than hard-coding
dimensions, so it fits whatever the base mesh produces.

`tools/build_wizard.py` is the previous, fully procedural character. It is kept
because it needs no third-party tooling at all, but it is no longer what ships.
